# 12 测试计划

## 测试目标

验证系统能完成：

1. 用户注册登录闭环。
2. 商品发布审核闭环。
3. 买家交易闭环。
4. 卖家订单管理闭环。
5. 管理员运营处理闭环。
6. 权限和资源归属校验。
7. 商品并发下单控制。

## 创建订单

| 编号 | 场景 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- | --- |
| O01 | 创建订单成功 | 商品 ON_SALE，买家不是卖家 | POST /api/orders | 订单 CREATED，商品 LOCKED |
| O02 | 买自己的商品 | 当前用户是卖家 | 创建订单 | 返回不能购买自己的商品 |
| O03 | 商品已锁定 | 商品 LOCKED | 第二个用户创建订单 | 返回商品不可售 |
| O04 | 商品下架 | 商品 OFF_SHELF | 创建订单 | 返回商品不可售 |
| O05 | 并发创建订单 | 两个用户同时买同一商品 | 同时调用创建订单 | 只有一个成功，另一个失败 |

并发控制验收：创建订单必须通过以下条件更新锁定商品：

```sql
UPDATE market_goods SET status = 'LOCKED' WHERE id = ? AND status = 'ON_SALE';
```
